# Fly Command Mod

Minecraft Java Edition **1.20.1** / **Forge 47.x** 模组。

## 功能

在聊天框输入命令切换飞行模式：

- `/fly true` — 开启飞行模式
- `/fly false` — 关闭飞行模式

## 构建

需要 JDK 17：

```bash
./gradlew build
```

构建产物位于 `build/libs/flycommand-1.0.0.jar`，放入 `.minecraft/mods` 目录即可使用。

## 环境要求

| 环境 | 版本 |
|------|------|
| Minecraft | 1.20.1 |
| Forge | 47.2.0+ |
| Java | 17 |
